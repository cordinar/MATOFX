# Welcome to MATOFX SPDM™

MATOFX SPDM™ is a place to **run your engineering simulation tools and keep their
results organised**. Instead of running tools by hand on your own computer and
saving files wherever they land, you run them through MATOFX in your web
browser. MATOFX queues the work, runs it for you, keeps every result together
with the inputs that produced it, and lets you find and compare past runs later.

People sometimes call this kind of system an **SPDM platform**. SPDM stands for
*Simulation Process and Data Management* — software that manages the **process**
of running simulations and the **data** they produce, so a team can work in a
tidy, repeatable way.

You don't need to install anything. Everything happens in your web browser. The
next page explains how to sign in.
