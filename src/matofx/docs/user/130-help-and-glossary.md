# Help and glossary

## Getting help inside MATOFX SPDM™

The **help button** (the question mark in the header) opens this documentation
from anywhere — or the **Tutorials** page. On many pages the documentation opens
straight to the chapter about the page you're on.

## Contacting support

If your administrator has set a **support contact**, it appears at the bottom of
every page. Use it for problems your administrator can't resolve. For anything to
do with access — accounts, passwords, which tools you can see — your administrator
is the right first contact.

## Glossary of terms

- **Job** — one run of a tool with a particular set of inputs.
- **Tool** — a piece of simulation or calculation software, added by your
  administrator.
- **Workflow** — several tools run together in order, with results passed from one
  to the next.
- **Project** — the top-level container for related work.
- **Scenario** — a grouping of jobs inside a project.
- **Parametric study** — running a tool many times across a range of inputs.
- **Optimisation** — automatically searching for the inputs that give the best
  result.
- **Goal** — what an optimisation tries to make best (a value to minimise or
  maximise).
- **Limit (constraint)** — a condition a result must satisfy to count; a result
  that breaks one is rejected as *infeasible*.
- **Trade-off front (Pareto front)** — when an optimisation has several competing
  goals, the set of results where you can't improve one goal without giving up
  another; you pick the balance you prefer from it.
- **Surrogate model** — a fast stand-in that predicts what a slow tool would say.
- **Job cohort** — the batch of real runs a surrogate model learns from, gathered
  from across the workspace by tool and version.
- **Key Performance Indicator (KPI)** — an important result value worth tracking.
- **Verification and Validation (V&V)** — checking that a tool was built correctly
  and gives trustworthy results.
- **Capability** — an extra right added on top of a normal account.
- **Approver** — a person who must sign off certain jobs before they run.
- **Curator** — a person who looks after a shared catalogue (files, materials, or
  V&V records).
- **Tutorial** — a document or video your organisation uploads about its own tools.
- **Administrator** — the person who runs your MATOFX SPDM™ site.
