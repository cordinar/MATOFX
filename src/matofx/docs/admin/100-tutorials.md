# Tutorials (uploaded guides and videos)

**Tutorials** are documents and videos *you* upload about *your* organisation's
tools and workflows. Manage them in **Admin → Tutorials management**.

## Tutorials vs this built-in documentation

It's worth being clear about the two:

- **This documentation** (the User and Administrator guides) is about **MATOFX SPDM™
  itself**. It ships with the software and is written by Funis.
- **Tutorials** are about **your specific tools and workflows**. You write and
  upload them, and they're particular to your installation.

The two sit side by side: a user reading about a tool can see both the MATOFX
documentation and your tutorial for that tool.

## Uploading a document or video

You upload a tutorial as either a **document** (a PDF) or a **video**. Give it a
title and a short description so users know what it covers.

## Scope: general, per-tool, or per-workflow

Each tutorial has a **scope**:

- **General** — shown to everyone on the home page (for example, a "getting
  started at our company" guide).
- **Per-tool** — shown next to a particular tool.
- **Per-workflow** — shown next to a particular workflow.

A tool or workflow shows at most one active document and one active video, so the
surface stays uncluttered; general tutorials have no such limit.

## Activating and deactivating

You **activate** the tutorial you want users to see, and **deactivate** it to
hide it from the Home page without losing it (you can re-activate it any time).

## Publishing a new version (and keeping the old one)

To replace a tutorial with a newer file, use **Update** on its card. Attach the
replacement, adjust the title or version label if you like, and publish. The new
version takes over as the live one, and the old version is **archived** — kept as
a *previous version*, listed (collapsed) beneath the current one so you can still
preview your history. Archived versions are never shown to users.

Tutorials are **never deleted** — there's no delete button. Updating always keeps
the prior version, so your tutorial history is preserved.
