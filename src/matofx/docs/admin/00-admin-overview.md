# Administrator overview

This guide is for the people who **run** a MATOFX SPDM™ site, not just use it. It
appears only to administrators.

## What an administrator does

As an administrator you look after the things ordinary users rely on:

- **People** — creating accounts, setting what each person can do, and grouping
  people into teams.
- **Tools and workflows** — adding the simulation tools your users run, and
  combining them into workflows.
- **Site settings** — branding, which features are switched on, where files are
  stored, and how the site behaves.
- **Oversight** — approvals, the audit record of what happened, and usage
  statistics.

## The Admin menu

Everything above lives in the **Admin** group, pinned to the **bottom** of the
sidebar, which only administrators can see (its heading and entries carry a small
padlock). Each entry is covered in its own chapter of this guide. A few
administrator-only entries also sit inside the ordinary groups next to the
feature they manage — for example **Custom Workflows inspector** and **Project
metadata** under Dashboard, **Explore MATOFX database** under Libraries, and
**Audit log** and **V&V records inbox** under Governance — each marked with the
same padlock.

## Super user vs administrator

There are two administrator account types:

- **Administrator** — can do the day-to-day administration this guide covers.
- **Super user** — the highest level of access. The very first account on a new
  MATOFX site is a super user, and super users can do everything an
  administrator can, plus the most sensitive actions.

Where a task needs super-user access specifically, this guide says so.

## A safe first-day checklist

If you've just taken on a new or fresh MATOFX site, a sensible order is:

1. Confirm you can sign in and reach the **Admin** group at the bottom of the sidebar.
2. Set the site's **branding** and **support contact** so users know where they
   are and who to ask for help.
3. Create a few **user accounts** and any **teams** you need.
4. Add or check the **tools** your users will run.
5. Decide which optional **features** to switch on.
6. Confirm **email** is working so notifications reach people.

Each step has its own chapter later in this guide.
